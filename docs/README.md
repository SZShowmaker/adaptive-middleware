| QoS 配置 | [默认策略与 QoS 表单](QOS.md) | 使用默认值，按需修改参数，配置实例/消息覆盖并排查兼容性。 |
| 4 | [命令行参考](CLI.md) | 指定工程和输出目录，写重复执行的生成命令。 |

| 接手开发 / 新开 AI 对话 | [开发交接与前情提要](../DEVELOPMENT_CONTEXT.md) | 了解项目背景、已确认约定、代码入口、验证范围和后续方向，再执行本次任务。 |

## 本仓库常用术语

| 术语 | 在这里的含义 |
|---|---|
| 类型文件 | 描述消息结构的 JSON，比如每个目标有哪些字段。 |
| 工程 | 类型、App、连接、部署的一组配置，不等同于一个 C++ 可执行程序。 |
| App / App 实例 | App 定义提供哪些输出、需要哪些输入；实例是某一次部署的身份，例如前摄像头和后摄像头可使用同一个 App 定义。 |
| 服务接口 / Event | 服务接口把一组对外消息放在一起；Event 是其中一种可发布订阅的完整消息。 |
| 输入/输出分组（逻辑端口） | App 使用某个服务接口的配置名称；GUI 默认建立一个输出组、自动命名输入组，按需在高级设置中调整。不是 UDP/TCP 的数字端口；操作见 [界面指南](QUICKSTART_GUI.md#3-配置输出和输入)。 |
| SDK | 为某个目标平台准备好的头文件、库和 CMake 配置。Linux ARM SDK 不能拿去链接 Windows 程序。 |
| Gen / 生成器 | 开发电脑上运行的代码生成工具。本工具先生成 IDL，再调用 Fast DDS-Gen 生成 DDS 相关 C++。 |
| src-gen | 0.2 的完整交付根目录；包含 generated/ 接口源码、公共模块、三平台依赖、CMake、清单和手册。 |
| DTO | 业务使用的普通 C++ 消息对象；当前在它与 DDS 内部消息对象之间进行转换。 |
| Network Binding | 把公共 CM 通信操作落实到具体通信协议的一层实现，目前只有 Fast DDS。 |

文档中的 `/path/to/...`、`C:/tools/...` 均是占位示例，必须改成本机真实路径。命令的工作目录会在各节标明；除非另有说明，`./amw` 在本仓库根目录运行。

应用启动时的网卡选择和初始发现对端覆盖见 [应用 API：启动网络](app-guide/API.md#启动时选择本机网络)。
